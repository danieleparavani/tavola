Collega il laboratorio generativo

La chiave viene inviata soltanto al server locale sul tuo computer e verificata con OpenAI. Se accettata, viene cifrata e salvata su disco (fuori dal versionamento) così da restare disponibile dopo un riavvio del server, senza doverla incollare di nuovo ogni volta. Non compare mai nei log né in chiaro nei file del progetto.

Non usare la password di ChatGPT. Serve una API key creata nella piattaforma OpenAI. La fatturazione API è separata dall’abbonamento ChatGPT.

Passaggi

1. Apri la pagina ufficiale delle API key.
2. Crea una nuova chiave per Tavola.
3. Copiala una sola volta.
4. Torna qui e incollala nel campo protetto.
5. Premi Collega.
